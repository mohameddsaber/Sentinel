Privacy_Policy.md

Last compiled:

Your privacy is structurally guaranteed. Sentinel operates on a local-first node architecture, ensuring your browsing vectors never leave your terminal.

Data Collection & Usage

Sentinel requires specific browser API access to function. Operations are scoped strictly:

  • Tabs & URL Access: We parse active URLs to evaluate heuristic rules against your Deep Work state. This calculation occurs entirely locally using an embedded AI scorer. Zero URLs are transmitted externally.
  • Storage: Focus policies, blacklists, and session logs are written directly to local browser storage APIs.
  • Scripting: Executed uniquely to render intervention UI elements (Hard/Soft blocks) on active DOMs.

Local ML Processing

Sentinel distributes a lightweight tensor model upon installation. This model evaluates page vectors and context locally within the V8 engine constraints. Cloud inference is strictly prohibited.

Data Sovereignty

Sentinel does not extract, rent, or vend personal identifiers. Session telemetry and focus metrics are generated exclusively for local review.

Protocol Updates

We may update this policy document to reflect architectural or regulatory patches. Material state changes will be documented on this domain endpoint.

Establish Contact

For operational inquiries or audits, ping our support endpoint listed on the official extension registry.
