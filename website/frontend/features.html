Core Specifications

System Architecture

Sentinel provides a comprehensive toolkit to help you break bad habits and stay focused on what truly matters.

Heuristic Loop Detection

Sentinel executes a background daemon to analyze your tab-switching and scroll vector behavior. When you enter a "distraction loop" (rapidly traversing between non-productive nodes like social media or news), the system identifies the pattern and initiates a gentle "soft block" intervention protocol.

[ Terminal Output Visualization ]

Strict Focus Enforcement

Initialize Deep Work mode to enforce absolute constraints. In this state, explicitly blacklisted nodes trigger a "Hard Block" wall, impossible to bypass until your session executes completely. Soft blocks handle borderline nodes, prompting a confirmation dialogue before access is granted.

[ Hard Block UI State ]

Local Embedder Node

Data privacy is structurally guaranteed. Sentinel leverages a local machine learning embedding model inside your active browser environment to classify DOM content. Zero outbound telemetry for your browsing vectors. Processing and policy enforcement run 100% locally.
